# Hello World - Tara El Khoury

Lab 11 - Configuration and Deployment Tools

## Description
A simple C# console application that displays:
Hello, World from Tara_ElKhoury!

## Compile and Run
Requirements: .NET SDK 3.1

Run:
dotnet run

## Build Windows Executable
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true

## Execution
Run HelloWorld_Tara_ElKhoury.exe from the published output folder.
